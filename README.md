A professional, responsive, and elegant personal portfolio website designed to showcase my skills as a Frontend Developer and Prompt Engineer.

Built with pure HTML, CSS, and minimal JavaScript, this site features a modern aesthetic inspired by professional deep-red tones and clean typography.

✨ Features
Responsive Design: Fully functional on Desktop, Tablet, and Mobile devices.
Modern UI/UX: Clean layout using the 'Poppins' and 'Playfair Display' fonts.
Semantic HTML5: Accessible and well-structured code.
Interactive Elements: Hover effects, smooth scrolling, and a working mobile navigation toggle.
Showcase Sections:
About Me: Professional summary and language proficiency.
Skills: Grid layout highlighting technical expertise.
Journey: Timeline view of Education and Experience.
Projects: Cards displaying personal work (e.g., Motive2Meme).
Contact: Functional layout with contact details and a form UI.
🛠️ Tech Stack
This project is built without any external frameworks to demonstrate core web development skills:

HTML5
CSS3 (Flexbox, Grid, CSS Variables, Media Queries)
JavaScript (Vanilla JS for mobile menu)
Google Fonts (Playfair Display & Poppins)
Material Icons (Google Fonts Icons)
