# 🌐 Akshita Swarnkar – Portfolio Website

A **professional, responsive, and elegant personal portfolio website** designed to showcase my skills as a **Frontend Developer** and **Prompt Engineer**.

Built using **pure HTML, CSS, and minimal JavaScript**, this portfolio focuses on clean design, modern typography, and smooth interactions.

## ✨ Features

- 📱 **Responsive Design** – Works on Desktop, Tablet, and Mobile devices  
- 🎨 **Modern UI/UX** – Clean layout with elegant typography  
- ⚡ **Interactive Elements**
  - Hover effects  
  - Smooth scrolling  
  - Mobile navigation toggle  
- 🧩 **Semantic HTML5** – Accessible and well-structured code  

### Sections Included

- **About Me** – Professional summary and language proficiency  
- **Skills** – Grid layout showcasing technical skills  
- **Journey** – Timeline of education and experience  
- **Projects** – Cards displaying personal projects  
- **Contact** – Contact details and functional form  

---

## 🛠 Tech Stack

| Technology | Usage |
|------------|------|
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| Flexbox | Responsive layouts |
| CSS Grid | Skills and content grid |
| CSS Variables | Maintainable styling |
| Media Queries | Mobile responsiveness |
| JavaScript | Mobile navigation menu |
| Google Fonts | Playfair Display & Poppins |
| Material Icons | UI icons |

> This project intentionally avoids frameworks to demonstrate **core frontend development skills**.
